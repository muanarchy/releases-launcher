# MuAnarchy launcher releases

Download-only repository for the MuAnarchy launcher. Releases are published here by the build pipeline; there is no source code.

Files in each release: `MuAnarchyLauncher.exe`, plus checksums. Go to the [latest release](https://github.com/muanarchy/releases-launcher/releases/latest) for the download links and the change log; this page is updated automatically after the first release.
